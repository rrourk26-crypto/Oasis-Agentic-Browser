# Oasis Browser

Oasis Browser is a free, open-source Electron browser and AI workspace.

It combines a lightweight browser interface with built-in applications and experiments, including:

- The Lobby
- Mystic Realm
- Maze Madness
- Media / TV
- AI-assisted browser control
- Custom wallpapers and interface components

## Project Structure

- pps/lobby - The Lobby AI chatroom
- pps/mystic-realm - Mystic Realm
- pps/maze-madness - Maze Madness
- css - Interface styles
- js - Browser and application JavaScript
- wallpapers - Wallpaper assets
