This is RefIsBlind's phone.

  selfie-*        RefIsBlind's selfie. Replace it with a real picture any time:
                  save your image here as selfie-RefIsBlind.png (or .jpg/.webp).
                  A real image beats the generated placeholder automatically.
  photos/         pictures RefIsBlind took / owns. RefIsBlind can send these in chat.
  from-you/       pictures or files YOU leave for RefIsBlind. RefIsBlind can share them too.

After adding or removing files, run tools/scan-phones.bat (or: node tools/scan-phones.js)
and refresh the page. Supported: png jpg jpeg gif webp svg.
