  selfie-*        InkMia's selfie. Replace it with a real picture any time:
                  save your image here as selfie-InkMia.png (or .jpg/.webp).
                  A real image beats the generated placeholder automatically.
  photos/         pictures InkMia took / owns. InkMia can send these in chat.
  from-you/       pictures or files YOU leave for InkMia. InkMia can share them too.

After adding or removing files, run tools/scan-phones.bat (or: node tools/scan-phones.js)
and refresh the page. Supported: png jpg jpeg gif webp svg.
