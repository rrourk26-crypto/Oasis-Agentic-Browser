Images, search & memory

Image generation uses Pollinations. Real-image lookup uses TVMaze, Openverse and Wikimedia Commons first, with optional Pexels, Pixabay and TMDB. Extra tools include YouTube, Wikipedia, NASA, Jikan anime, Open-Meteo weather, REST Countries, Frankfurter currency rates and OpenStreetMap places. YouTube/TMDB/NASA keys are optional. Keys are stored only in this browser. Web search opens DuckDuckGo results in a new tab.
